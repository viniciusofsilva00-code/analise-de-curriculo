0. Como avaliar

As duas primeiras opções usam o seu plano Claude, sem chave de API.

recomendado · plano Claude · via GitHub

Avaliar daqui, pelo GitHub. Funciona como no oficina_ia: o site envia os currículos para o seu repositório privado de dados, o Claude Code avalia lá com o seu plano e o painel abre nesta página. Leva uns 5 a 15 minutos.

plano Claude · no claude.ai

Avaliar no claude.ai, na hora. O mesmo app publicado como artifact usa a sua assinatura direto no claude.ai.

abrir no claude.ai →

Ou use uma chave de API (Claude, GPT, Gemini ou Workers AI). Cada provedor guarda a própria chave, só neste navegador. A chave vai direto para o provedor escolhido e nunca entra no processo.json nem no painel exportado. Cada clique em Avaliar é uma chamada paga na conta do provedor.
